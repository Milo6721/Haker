# Osada — symulator życia (sandbox à la The Sims)

Otwórz `osada/index.html` w przeglądarce (bez serwera, bez zewnętrznych zależności).

- Mieszkańcy mają potrzeby (głód, energia, rozrywka, towarzystwo), charaktery, nastrój, pieniądze, relacje i wspomnienia.
- Decyzje podejmują sami (utility AI): jedzą, śpią, pracują, łowią ryby, grają na pianinie, rozmawiają, flirtują, kłócą się, zakochują się, zakładają rodziny i dorastają.
- Ty: budujesz (ściany, podłogi, meble, drzewa, woda), przenosisz ludzi, rozmawiasz z nimi tekstem, wywołujesz wydarzenia (impreza, deszcz, meteoryt, eliksir miłości…).
- Dzień/noc, pogoda, losowe wydarzenia, zapis w przeglądarce (localStorage).

Pliki: `js/world.js` (teren, A*), `js/chars.js` (AI postaci), `js/sim.js` (czas, wydarzenia), `js/render.js` (grafika), `js/ui.js` (interfejs).
